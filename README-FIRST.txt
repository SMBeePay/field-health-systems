FIELD HEALTH SYSTEMS — APPROVED LOGO PACKAGE

SOURCE OF TRUTH
The included APPROVED-BRANDING-GUIDE.png is the approved branding sheet.
All logo assets in this package are extracted from that exact sheet.

IMPORTANT
The approved branding sheet itself is raster artwork generated during concept development.
Therefore the files named *approved.svg preserve the exact approved pixels inside an SVG
container. They are intentionally NOT manually redrawn. This prevents another mismatch in
the FHS geometry or, especially, the grass treatment integrated into the bottom of the S.

For Claude Code / website use:
- fhs-horizontal-approved.svg — preferred website header
- fhs-primary-approved.svg — full primary lockup
- fhs-mark-approved.svg — compact FHS mark
- fhs-icon-approved.svg — icon treatment
- transparent 6x PNG files are supplied for platforms that do not accept SVG

DO NOT use any earlier Field Health Systems logo packages from this conversation.

PRODUCTION VECTOR NOTE
A genuinely editable path-based SVG cannot be guaranteed pixel-identical to generated raster
artwork without a professional manual vector reconstruction and proofing process. The exact
SVG assets here prioritize fidelity to the approved sheet rather than pretending an approximate
redraw is exact.
